# Attribution

The evidence skill borrows presentation conventions and proof standards from two public projects, and `scripts/evidence_publish.py` derives its pull-request markup from one of them.

- `vercel-labs/before-and-after` (https://github.com/vercel-labs/before-and-after), `skill/scripts/format.mjs` at commit `8306d34f459b6704e08e6adb5829fcddb0dc3557` (2026-09-02), PolyForm Shield License 1.0.0, copyright (c) 2026 James Clements. Ported to Python in `evidence_publish.py`: the `<!-- before-and-after:start -->` / `<!-- before-and-after:end -->` markers and their single-block replacement rule, the two-column Before/After image tables, the `Preview` label for after-only media, own-line videos that GitHub renders as players, the two-step HTML `<video>` comparison table once attachment URLs exist, the whitespace-free relative media paths that `gh --attach` rewrites, and the `gh pr edit --body-file --attach` publish sequence. The labelled two-up presentation of `comparison.html` follows the same project. A copy of the license is `LICENSE-before-and-after.txt`; this notice must stay with the derived code. Not taken: `agent-browser` capture, Vercel deployment authentication, the Node runtime. Added here: content-hash receipts, manifest and hash validation before upload, path containment, secret checks, foreign-block detection and rebasing on the latest body, provenance lines, read-back verification with restore, and deferral without `gh --attach`.
- `poteto/verification-skill-example`, `.cursor/skills/verify-atlas/SKILL.md` (https://github.com/poteto/verification-skill-example): the proof standard - drive the real user path, show the triggering action and the stable end state, verify side effects, never accept an image alone as proof. No code was copied.

Differences in capture: the driver is a Chromium-family browser spoken to over the DevTools Protocol from Node's built-in WebSocket, with Python standard library only for everything else; the video original is a Motion-JPEG AVI assembled from the browser's own frames, converted only optionally; nothing is harness-specific and no Cursor-only logic is used.
