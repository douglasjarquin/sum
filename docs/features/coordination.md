# Coordination and delegation

Journeys the coordinator, workers, and developers take through `sumctl`, Git and the typed HC boundary.
Automated rows name source drivers, not an assertion that the current candidate has passed them.
Historical scenario identifiers are retained for evidence continuity; retired API assertions do not certify HC behavior.
Manual gaps remain explicit until a candidate-specific run supplies the evidence.
