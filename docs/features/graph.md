# Code graph per checkout

The pinned codegraph (`npm:@colbymchenry/codegraph` 1.5.0) builds one `.codegraph/` index local to a task checkout, only when the coordinator requests it with `graph init`.
Ordinary checkout creation and verification never run it. A missing, failing, or unconfirmed index degrades explicitly to source inspection, and the brief says which state holds.
The graph assists exploration; it never replaces `mise run verify`, a feature-map row, or the coordinator's independent run and review.
The implementation lives in `go/internal/graph/init.go` (the request path, admission, and confirmation), `go/internal/graph/graph.go` (the pinned tool and snippets), and `go/internal/graphview/graphview.go` (the recorded summary and views).
