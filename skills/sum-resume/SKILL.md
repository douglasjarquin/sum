# Resume

Read the durable task note and approved scope before taking action.
Inspect actual Git branch/worktree/status and candidate content, saved reports, required command output, open questions, actual answers, and whether each answer was applied.
Preserve all unfinished work.
A remembered address, terminal name, report, or old commit is a clue, not current authority or proof of completion.

Use the installed `hc --skill` and relevant help.
Before any delegation or follow-up, apply [Work's native prerequisite](../sum-work/SKILL.md#native-prerequisite).
Do not address an empty target, fabricate HC identity, map an old TUI pane to HC, or import an arbitrary foreign PTY.
Inspect exact saved native addresses with `hc get` and relevant output/status to establish the current program, parent relationship, task, and eligible recipient.
The same address may now run a shell or a different conversation.
HC keep recovery restores a shell, not an agent session; exiting an agent to a shell need not end its children.

Reconcile what actually exists before launching or sending anything:

- A completed report is a claim to inspect against the actual candidate and required checks.
- A live terminal with `first_message.sent: false` has no delivered assignment; inspect readiness and output before deliberate delivery.
- An uncertain launch or send may have succeeded; inspect native state, output, and reports instead of blind duplication.
- A message wake may precede actual incoming input; wait for the input rather than scraping it from the wait result.
- A timeout, busy/blocked status, or returned shell is not success or a reason to force input through a dialog.

If the parent/report destination no longer hosts the intended active eligible agent, keep the report and deliberately reestablish the recipient before sending.
Do not type task instructions into a remembered shell or automatically restore an agent session.
Ask the user only for essential missing authority or information; record the question and actual answer in the note.
Restart no shared core, seize no foreign terminal, and implement no collector, replay loop, mailbox, or return service.

Choose the next bounded action from current evidence: continue direct work, steer an unfinished verified helper, deliberately relaunch after conclusive resolution, inspect results, or report a prerequisite/blocker.
For a completed assignment, read and preserve the report, then close the exact owned worker under [Finish](../sum-finish/SKILL.md).
Use a fresh worker for subsequent fixes or review, carrying forward saved findings and the current candidate.
Record the actual result and next action in the note.
Use [Finish](../sum-finish/SKILL.md) for final delivery only after final-candidate obligations are accounted for; completed-worker cleanup happens when its report is collected.
