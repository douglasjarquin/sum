# Decisions

Copy this file to `.sum/decisions.md` the first time a standing ruling or an answered question should be indexed.
Append-only. Do not edit or delete a line. A newer line supersedes an older one on the same key.

Task questions and answers stay in `.sum/tasks/` through `sumctl ask` and `sumctl answer`.
This ledger is the standing index: read it before asking again.
The question file remains the record of the user's words.
Only the coordinator appends. A worker may read.
